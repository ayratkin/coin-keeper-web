# pages

Эта папка намеренно пустая.

Next.js ищет роутеры сначала в корне (`app/`, `pages/`), а затем в `src/`.
Пока здесь существует папка `pages/`, Next.js не будет считать FSD-слой
`src/pages` роутером Pages Router.

Роутинг приложения живёт в корневой папке `app/` (App Router),
а FSD-слои — в `src/`.
